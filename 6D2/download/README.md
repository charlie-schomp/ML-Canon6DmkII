| **1.1.1** | [ML-6D2-fw1.1.1-v90.zip](ML-6D2-fw1.1.1-v90.zip) | tested on a camera; includes the installer `ML-SETUP.FIR` |
| 1.2.0 | — | not supported in current releases |

Copy **`autoexec.bin`**, the **`ML`** folder and (first install only) **`ML-SETUP.FIR`** to the
card. The `extras` folder in the zip holds the user guide, tools and test sheets; it stays on your
computer. Full steps are on the [main page](../../README.md#install).

`SHA256SUMS.txt` inside each zip lists checksums for the camera files, if you want to verify a
download.
