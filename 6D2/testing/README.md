# Testing

Procedures for people helping to test new versions on a real camera.

| File | |
|---|---|
| [`fast-card-test.md`](fast-card-test.md) / [`.pdf`](fast-card-test.pdf) | finds the fastest formats a fast SD card can record; about an hour. The PDF is a fillable form. |
| [`retest-v76.md`](retest-v76.md) | 5-minute check of the latest changes |

After a session, run [`../tools/cardcheck.py`](../tools/cardcheck.py) on the card and send the
report with your results.
