# Testing

For people helping to test new versions on a real camera.

| File | |
|---|---|
| [`field-test.md`](field-test.md) | checks a build from install to results: menus, exposure tools, frame guide, formats, takes in a row, clip info, audio. About an hour |

After a session, run [`../tools/cardcheck.py`](../tools/cardcheck.py) on the card and send the report with your results.
